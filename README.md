
# Basic-Calculator
# 🧮 Basic Calculator (Python)  A user-friendly Python-based calculator capable of performing fundamental arithmetic operations such as addition, subtraction, multiplication, and division. Designed for beginners to understand core Python concepts like functions, user input, and control flow.

---

## ✅ Features

- ➕ **Addition**
- ➖ **Subtraction**
- ✖️ **Multiplication**
- ➗ **Division**
- 📱 **Command-line Interface**
- ❌ **Handles division by zero errors gracefully**
- 🔁 **Continuous calculations until the user exits**

---

## 🧰 Technologies Used

- **Python 3.x**
- No external libraries required

---
